# Project 2: Exploratory Data Analysis (EDA)
## Overview
This project focuses on Exploratory Data Analysis (EDA) of an e-commerce dataset. The objective is to analyze the dataset, understand data distributions, identify trends, detect outliers, and generate meaningful insights using statistical and visual analysis techniques.
## Objectives
- Understand the structure of the dataset
- Calculate descriptive statistics
- Identify missing values
- Detect outliers
- Analyze data distributions
- Discover relationships between variables
- Summarize key findings
## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Visual Studio Code (VS Code)
## Dataset Features
- Quantity
- UnitPrice
- ItemsInCart
- TotalPrice
## Analysis Performed
### 1. Data Inspection
- Viewed dataset structure
- Checked column names and data types
- Examined dataset dimensions
### 2. Missing Value Analysis
- Identified and verified missing values
### 3. Descriptive Statistics
- Mean
- Median
- Minimum Value
- Maximum Value
- Standard Deviation
### 4. Outlier Detection
- Box Plot analysis for TotalPrice

### 5. Distribution Analysis
- Histogram of TotalPrice

### 6. Correlation Analysis
- Heatmap showing relationships between numerical variables

## Key Findings
- Dataset contains 1200 records.
- Mean Quantity: 2.95
- Median Quantity: 3
- Average Unit Price: ₹356.41
- Average Total Price: ₹1053.97
- TotalPrice contains a few high-value outliers.
- Most orders are low-to-medium value purchases.
- UnitPrice and TotalPrice show a strong positive correlation (0.72).
- Quantity and TotalPrice show a moderate positive correlation (0.62).

## Visualizations
- Box Plot
- Histogram
- Correlation Heatmap

## Conclusion
Exploratory Data Analysis helped uncover patterns, trends, and relationships within the e-commerce dataset. The analysis revealed customer purchasing behavior, identified outliers, and highlighted the variables that most influence TotalPrice. These insights provide a strong foundation for future business analytics and machine learning projects.
